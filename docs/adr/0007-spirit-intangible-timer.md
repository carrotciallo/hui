# 0007 灵体态是限时穿透态：不再"仍是实心一整块"

## 状态

已接受（2026-11-06）· 部分取代 [ADR-0005](0005-red-hot-forge.md)

## 背景

ADR-0005 把灵体定为纯读数，并明确写着：

> **灵体框仍是实体**：边框只是视觉，身体碰撞箱不变（仍是一整块实心盒），所以灵体照常参与双人动量交换。

这在当时是对的——"本期只做形态切换，不做形态功能"。但关卡跑起来之后暴露两件事：

1. 四条边全碎在玩家眼里就是"我碎了、该有代价也有补偿"，而现状是**只有代价**：照旧撞墙、照旧踩刺死、照旧被岩浆烫死，形态本身什么也没给。
2. 双人对撞是核心机制，一个"碎了还照样交换动量"的 A 让碎框方毫无处境变化，规则读起来像 bug。

Issue #64 要求把灵体做成真正的状态：不可冲刺、不与任何实体交互、有存在时限、消散时把身上的钥匙吐回世界。这直接推翻 0005 的"仍是实心"。

## 决策

**灵体态 = 限时的无敌穿透态，落地豁免，消散即死。**

- **穿透包括实心地形**。不只是免伤害：墙、地板、岩浆体、地刺、门、绳、对方玩家一律不互动，碰撞箱在灵体期间关闭。
- **唯一豁免是落地站立**。地面探测不看碰撞箱（本来就是全层 BoxCast），所以灵体仍站在实心格顶上。没有这条豁免，穿透态一开就是坠出地图，机制等于自杀。
- **有存在时限**，时长是 Tuning Lab 调参数；从普通态进入灵体的那一刻起算，中途不因传送/移动暂停或重置。
- **计时耗尽 = 死亡**，走统一销毁入口，与塌框、地刺同一个必达点。
- **消散时吐钥匙**：身上有钥匙（持有一把）且所在格不是实心时，在脚下生成一把临时钥匙；临时钥匙会被地图重置清掉。被打断（传送、重生点刷新、调试）不产钥匙。
- **每人名下最多一把钥匙**，拿着再捡无效、钥匙留在原地。这条与"吐钥匙"配套：不封顶的话一个人可以囤光全关钥匙，吐回来的却只有一把，门永远差一把。

取代 0005 中的表述：

| 0005 原文 | 现在 |
| --- | --- |
| 灵体框仍是实体（一整块实心盒） | 灵体无实体，碰撞箱关闭，仅落地判定豁免 |
| 灵体照常参与双人动量交换 | 灵体与对方玩家互穿，不参与对撞结算 |
| 灵体只是读数、无行为 | 有冲刺禁用、穿透、计时、消散死亡、吐钥匙五项行为 |

0005 的红热 / 锻造 / 碎边 / 形态组合语义继续有效，包括"灵体不可复锻"。

## 后果

- **灵体是逃生窗，不是无敌逛关卡**：六秒左右够穿过一段墙找掩体、够把钥匙挪个位置，不够白嫖到关底。数值留在 Inspector，由策划在调参台定稿。
- **穿透 + 能站地会产生贴墙漂浮**：灵体横向穿过墙后仍贴在地形表面，视觉上像贴着地面飘。这是接受的设计代价，换掉它就得放弃落地豁免。
- **消散即死让"卡死在墙里"不复存在**：不再需要"从实心里探出头找支撑"这类补救，人原地冻结等结算，物理上无从卡起。
- **吐钥匙补上了软锁的半个洞**：灵体死会把吞掉的钥匙还回世界。另一半（全队死光时钥匙还在活人手里）明确**不**处理——那种情形要求玩家整关重打，重置会按关卡数据把原版钥匙放回原位，接受重开成本，不额外生成。
- **实现落点是一个派生只读量**（形如 `IsIntangible => form == Spirit`），在各交互入口引用，不复用 `IsDead` / `Suspended`——那两个各自带隐藏、冻结、团队结算、跟随宿主等副作用，语义都不吻合"仍可见、仍可动、仍被相机双人框住"。

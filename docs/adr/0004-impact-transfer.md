# 0004 双人撞击：只传递速度，受击方进入 v2

## 状态

已接受（2026-10-31）

## 背景

P1 只用 0.12s 输入硬直处理双人推挤，撞起来没有“速度等级”的公共语言，绳、冰、热锻也无法复用碰撞结果。策划要求横碰距离为 3（v2）+ 2（v1）+ 1（缓冲），且被撞方进入 v2。

## 决策

- 只处理横向撞击（接触法线 x 分量 ≥ 0.5），纵向踩头不参与传递。
- 由速度更快的一方作为攻击方；受击方在自己的碰撞回调里处理，天然不会双边重复触发。
- 攻击方挡位 ≥ v1 时，受击方进入 v2，按两段击飞：
  - 第一段：v2 速度，持续 `HorizontalPushDistance / v2速度`（3 格）；
  - 第二段：v1 速度，持续 `HorizontalPushFollowDistance / v1速度`（2 格）；
  - 结束后解除输入锁，保留 v1 速度交给正常减速，约再滑 1 格。
- 击飞期间忽略跳跃/冲刺输入并清空输入缓冲；挡位用 `SpeedTierProvider.Force` 覆盖当前档，避免被冲刺的 v1 请求压住。
- 击飞方向取“攻击方 → 受击方”的水平方向，不依赖物理后端给的法线朝向。
- 只把速度传给受击方，不反向减速攻击方；先避免复杂动量。
- 攻击方挡位低于 v1 时保留 0.12s 短硬直，普通推挤不变。
- 受击时抛 `ImpactInfo`（攻击方、受击方、法线、速度、挡位、接触点）；表面材质在 P4 实现 `IImpactReceiver` 并返回统一响应枚举。

## 后果

- 碰撞结果可以用挡位和距离验收；HUD 与描边直接显示 v2。
- 两段击飞是显式距离，调手感只改 `GameConstants` 和挡位速度。
- 反击/互撞的动量交换未实现，等 P2 手感验收后再决定是否补。

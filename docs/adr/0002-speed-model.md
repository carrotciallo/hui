# 0002 速度挡位：行为驱动状态，状态给速度

## 状态

已接受（2026-10-31）

## 背景

绳子、冰、热锻、大炮、门都依赖“当前速度挡位”。如果挡位由瞬时速度推导，冲刺、碰撞、重力等来源的边界很难稳定；如果挡位是独立状态，规则清晰，但需要行为显式申请。

## 决策

- 挡位是显式状态 v0–v4，由行为申请：冲刺 → v1，碰撞 → v2，重力 / 绳 / 炮 → v3，炮 +1 / 最大组合 → v4。
- 速度由挡位给出（`SpeedTierProvider.TargetSpeed`）；刚体实际速度可以因惯性短暂高于目标速度，例如冲刺后的减速缓冲。
- `PlayerMotor` 只读 `Tier` 和 `TargetSpeed`，不直接推导挡位。
- 保留替换点：继承 `SpeedTierProvider` 并重写 `Tick`，即可改成“速度推导挡位”的实现，`PlayerMotor` 不用改。该实现暂不提供。

## 后果

- 机关判定读挡位，不读瞬时速度，行为可预测。
- 冲刺距离 = v1 速度 × 冲刺时长；冲刺后的 +1 格缓冲由减速产生。
- v3 / v4 的来源和持续时间还需要在 P2 / P5 补齐规则。

# 0001 世界尺度：1 单位 = 1 格 = 16px

## 状态

已接受（2026-10-31）

## 背景

策划里的跳跃高度、冲刺距离、人物尺寸都以“格 / 像素”描述，但原型没有统一世界尺度，参数无法直接对应物理单位。

## 决策

- 1 Unity unit = 1 tile = 16 px，Sprite PPU = 16。
- 人物 13 px = 0.8125 unit。
- 跳跃高度 2 unit，跳远 3 unit，横冲 3 + 1 unit，上冲 6 / 8 unit。
- 灰盒、Tilemap、测量标记统一按 1 unit 一格摆放。

## 后果

- 走速由跳远和滞空时间反推：v0 = 4.7，跳跃初速 = 11.2（上升重力 3.2、下落重力 5.2）。
- 旧场景和旧参数需要重建；原型里的 4px 白块不再使用。
- 后续所有关卡距离都可以直接按格数写，不再做像素换算。

# 0003 关卡拓扑：单场景连续世界

## 状态

已接受（2026-10-31）

## 背景

L10 需要回到之前的关卡、撞烂旧路，并用相机视野收缩藏住终点。如果关卡是分立场景，需要额外的跨场景状态和回溯逻辑；对 Game Jam 来说成本过高。

## 决策

- Jam 版本使用单个连续场景，L0–L10 从左到右排布。
- 钥匙、传送门、质量、重生点直接存在场景对象上，不做磁盘存档。
- 传送门作为捷径 + 收集要素；全部点亮后开启 L10。
- 如果内容量超出单场景承受范围，再拆 additive scene，但保持同一个运行时世界。

## 后果

- 不需要 RunState 持久化和场景加载。
- 关卡边界、相机 clamp 和回溯路线需要在同一场景内统一规划。

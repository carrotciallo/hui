# 回 · 游戏设计文档（内容）

本文件收录场景内容、物件清单、关卡流程和待定内容。物件的具体操作规则与数值以[机制文档](./回-机制.md)为准。

### 墙面与地面

- 竖直绳子
- 地面绳子
- 冰块
- 伤害类：玉米糊（非牛流）、地刺
- 传送门
- 钥匙
- 过关门

### 机关与可交互物

- 方向转换器
- 木筏
- 滚木

- 重生点

物件行为、触发条件和相互作用见[机制文档](./回-机制.md)的“场景机制与材质交互”。

## 2. 关卡流程

关卡在画布上自左向右排列为 L0 → L10。以下保留画布中的设计意图与考察点。

### L0

- 熟悉冲刺，跳跃

### L1

- 利用横碰通过
- 利用上冲通过
- 引入重生点

### L2

- 复习冲刺方式，引入门与钥匙
- 玉米糊初见
- 绳子初见

### L3

- 冰块初见
- 利用破坏横竖两个方向的冰块通关
- 顺便了解冰块滑行的机制

### 绳子进阶

> 画布位置在 L3 与 L4 之间。

- 利用 v2 穿越绳子来通关
- A
- B
- 刺
- 绳子
- 下冲

### L4

- 引入转换器
- 点亮第一个传送门
- 引入支线
- 路面不平
- 利用竖直转水平通关
- 利用冰面的水平转竖直通关

### L4+

- 利用制造 L 道通关
- 绳子
- 右下 L 道
- B
- =》
- 复习绳子特性

> 该分区内另有 5 个未填写的「...」占位框。

### L5

> 画布位置在 L4 / L4+ 下方，作为其变体；三个节点由一条多目标连线串起。

- 和 L4 结构相似，缺少滑道
- 背景提示对撞，提供凹凸不平地面
- 利用滑道通关

### L6 综合

- 引入竖绳子。利用转换器竖直转横，再反弹撞碎墙

### L7

- 大炮登场

### L8

- 竖绳子复习 +「|」形性质引入

### L9

- ___与地刺的交互？

### L10

- 点亮全部传送门后开启
- 给小块质量 +1
- 开启后传送门关闭，二人一路创烂之前的路
- 在某一关利用绳子 + u + L 达到最大速度撞破墙壁
- 利用相机机制找到最终关卡
- 来场 boss 战 / 直接结束

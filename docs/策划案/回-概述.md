# 回 · 游戏设计文档（概述）

## 项目概述

《回》是一个围绕双人协作、速度变化与环境互动展开的2D平台解密游戏。两名玩家分别操控大框（A）和小块（B），通过框的形态变化及场景互动以改变速度

当前设计稿覆盖 L0–L10 的关卡构想、人物操作、速度等级、场景物件、数值规范及机关交互。剧情与美学方向尚未整理，单独预留文档接口。

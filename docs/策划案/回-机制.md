本文件收录人物操作、移动与速度、数值规范、场景规则和导图中的机制连线。场景物件及关卡内容目录见[关卡文档](./回-关卡(未完成).md)。

## 1. 人物与操作
### 相机
- 运动相机，根据二人的位置来缩放视野
### 两种体型

| 操控 | 说明 |
| --- | --- |
| wasd：大块（A） | 是一个框框 |
| 上下左右：小块（B） | 是一个小块 |

- 二者均可冲刺，跳跃，拿钥匙
- 二者质量相同
- 玩家间可以驮着走

### 冲刺

- 不可斜着冲
- 落地且未处于冲刺态开始冷却计时（0.5s）
- 一定要在空中才可以下冲
- 冲刺状态无重力

## 2. 场景机制与材质交互

### 绳子

- 竖着的绳子：可穿过 + 可反弹；可通过大块A的「|」形态黏附
- 地面绳子：可上不可下（平台
- v2 可穿，v3、v4 反弹并+1
- v2 强行下去，v3/v4 反弹并 +1

### 冰块

- 可加速（冰面）
- 可被 v2 破坏一整面
- 可滑行加速
- 红热态接触可只融化一格 

### 伤害物件

- 刺
- 岩浆：可用大块的 _ 形态通过
### 其他场景物件

- 传送门：需要靠近点亮才可使用；作为收集要素；双人站里面且同时按“下”键触发；会吞钥匙
- 钥匙：拾取后，给玩家头顶镀金；上冲撞天花板可将其拿下，变为类似玩家的实体
- 重生点：任意一名玩家接触即强制触发；两人以全新状态回到点的 A 左 / B 右固定位置，清空钥匙并重置地图。每次完整进入触发一次，全部离开后可再次触发；同一时间只有一个重生点激活。
- 过关门：得到质量之后才可被破坏



### 红热锻造（机关体系）
- 仅A可用
- A：边框受到 v2 速度撞两次后，变为红热态，仅重生或和冰块接触可解除；达到红热态后，边框受到v1速度即可被撞断，由虚线取代（保证A不会摔倒）；
- B用>v1的速度 即可进入A
### A的形态
- 所有形态下A均可
- u：大炮 ，存储B的进入速度等级，进入后A仍可移动跳跃冲刺，B再按冲刺键将自己射出，速度等级+1
- L：方向转换器:使B的v转向
- _：木筏 → 渡过岩浆之类
- |：在绳子附近按w可攀附，以达到电梯般的效果
- -：待定
- 空：无实体，一定时间内死亡 → 用于拿取墙中的钥匙


### 加速方法

- 碰撞
- 重力
- 弹力
- 大炮

## 3. 数值与规范

### 距离规范（暂定）

- 跳跃高度：2
- 最大跳远距离：3
- 横冲距离：3（v1）+1（减速缓冲）
- 叠罗汉状态下跳跃高度：0.5？（较小即可
- 横碰距离：3（v2）+2（v1） +1
- 上冲距离
- 最大组合上冲高度：8
- 最大单人上冲高度：6
- 美术绘制：基本格子 16x16 像素
- 人物：13x13pix


### 建筑物 / 道具规范

- 地刺：<0.5

## 4. DLC 机制

- 捡到钥匙后，v1 速度向上撞可将其撞出去，成为一个实体
- boss 战
- 若长时间卡关（不移动），小块会做梦以提示玩家
## 5. 关卡设计
- 主线包括机制的初见与进阶，支线用于考验机制的综合运用

### 主线最后一关
- 将所有传送门点亮,最后一关大门开启，小块获得质量+1
- 所有的过关门均可被撞碎
- 在之前的关卡中，找到一个地方，达到最大速度，撞破最坚硬的墙
- 利用相机的视野收缩机制找到通关地点

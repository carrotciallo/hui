# 角色故事像素画

这组素材都是 64×64、透明背景、原生像素绘制，建议在关卡编辑器中按 `4×4` 格摆放。

| 文件 | 场景 |
| --- | --- |
| `story_high_five.png` | A / B 在地面击掌庆祝 |
| `story_forge_breakthrough.png` | A 红热冲刺撞裂钢板，B 跟在后面 |
| `story_ice_slide.png` | 两人从冰坡上加速滑下 |
| `story_key_gate.png` | B 带着钥匙跑向大门，A 在旁边指路 |
| `story_checkpoint.png` | 两人在绿色重生旗前会合 |
| `story_hidden_passage.png` | A 看见 B 从隐藏墙的通道里现身 |
| `story_teleport.png` | A 进入传送门、B 从另一端出现 |

素材无碰撞、无文字、alpha 只有 0/255，适合作为地图中的叙事装饰或关卡缩略场景。
